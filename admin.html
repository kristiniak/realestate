Pripojenie k webu

Stránka ukladá zmeny priamo do vášho GitHub repozitára. Raz zadajte prístupový kľúč (token) a prehliadač si ho zapamätá.

Ako získať token (stačí raz)
  1. Na GitHube kliknite vpravo hore na svoj profil → Settings.
  2. Úplne dole vľavo Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Pomenujte ho (napr. „web admin“) a nastavte platnosť.
  4. Repository access: Only select repositories → vyberte repozitár s webom.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Kliknite Generate token, skopírujte ho a vložte sem. Nikomu ho neposielajte.

360° prehliadka interiéru

Každá miestnosť = jedna 360° fotka (ideálne pomer 2:1). Šípky medzi miestnosťami nastavíte tlačidlom „Šípky a pohľad“ – kliknutím priamo do fotky.

Body na ulici sú 360° fotky, ktoré návštevník otvorí panáčikom na mape. Body bez polohy na mape sú dostupné len cez šípky (napr. dvor za bránkou). Kategórie slúžia len na prehľad v administrácii – na webe sa nezobrazujú.
